# terminal-fun

**24 generative terminal animations and 8 small games, written in pure Python 3 with no dependencies.** They're made to run in a spare terminal while a long build, test run or AI coding agent works in another. An optional Claude Code hook can end the show with fireworks the moment the agent finishes.

**See every piece in colour: open [gallery.html](gallery.html)** (download it and open it locally; GitHub shows only the source). It is a cheat sheet with a still of each piece, regenerated by `python3 tools/gallery.py`.

### Highlights

- **No dependencies.** Python 3 standard library only, down to the PNG decoder, the audio synthesizer and the diff renderer.
- **A shared toolkit** (`fun/`): a diff-based frame renderer that sends only the cells that changed, synchronized output, a 1 fps focus pause, braille sub-cell drawing, and a WAV synthesizer that renders every ambient loop and sound effect at runtime.
- **Range:** physics and simulation (falling sand, the abelian sandpile, heat-diffusion fire, boids, space-colonization trees, a lensed black hole), 3D point clouds and glyph-mosaic shading, and games including a solver-checked Minesweeper variant and a twin-stick roguelite.
- **Built to be tested:** every piece takes `--frames N` and runs headless under a pty. `tools/test_render.py` checks the diff renderer against full redraws, and `tools/bench.py` measures CPU and bytes per frame.

## Install

You need Python 3.9 or newer (tested on 3.9 and 3.14) and a terminal with 256 colours (truecolor looks best). Sound is optional: it plays through `afplay` on macOS, or `paplay`, `ffplay` or `aplay` elsewhere.

```sh
git clone https://github.com/debanwita27/terminal-fun.git
cd terminal-fun
./wait-fun                  # a random animation, switching every 90 s
```

There is nothing to `pip install`. `wf` is a short alias for `wait-fun`. To put it on your PATH, symlink it: `ln -s "$PWD/wait-fun" ~/.local/bin/wait-fun`. The optional Claude Code wiring is below.

## Pieces

**Watch:** biplane, blackhole, campfire, catnap, celestial, codefire, daisy, dyna, excuses, fireworks, forest, hourglass, ink, jellyfish, koi, meltdown, moire, reef, sandpile, sharks, skyline, spacecol, swirl, tixy.

**Play:** bonkyon, bugsquash, bullethell, catstack, ducklings, forage, froghop, typewriter.

`./wait-fun list` prints each piece with a one-line blurb. The full tables, with flags and controls, are under [Animations](#animations) and [Games](#games).

## Quick start

```sh
./wait-fun install          # one-time: wire the Claude Code hooks + put `wait-fun` on PATH (uninstall to undo)
./wait-fun --watch          # loop of non-interactive pieces, a new one every 90s (same as `watch` or no args)
./wait-fun --play           # loop of games: quit one (q) for the next, Ctrl-C to stop (same as `play`)
./wait-fun watch reef       # run one non-interactive piece (extra args pass through)
./wait-fun play forage      # play one game
./wait-fun bonkyon --solve  # any piece by name, args passed through
./wait-fun list             # Watch / Play sections with blurbs and credits
./wait-fun credits          # credit and link for every piece (--markdown for a table)
./wait-fun --until-done     # cycle until any Claude session finishes (needs the hook), then pause on a fireworks finale naming it
python3 watch/campfire.py   # run a script directly from anywhere (Ctrl-C to quit)
```

`wait-fun` options: `--each SECONDS` (default 90), `--until-done`, `--fps N`, `--mute` (see [Sound](#sound)). `--only NAME`, `--games` and `--list` still work as older aliases. With `--until-done`, the first Claude session to finish ends the rotation: fireworks play with a banner naming its folder and last prompt, then hold until you press a key (back to the rotation, waiting for the next session) or `q` (quit). `wf` is a short symlink to `wait-fun` (a `fun` symlink can't sit next to the `fun/` package).

Games run with no time limit and no `--frames`. In the `--play` loop, quitting a game normally starts another random one; Ctrl-C ends the loop. Each game shows its own "Claude's done!" banner.

`wait-fun install` adds two hooks to `~/.claude/settings.json`, leaving your other hooks alone and saving a backup first: the status hook (so `--until-done`, catnap, hourglass, campfire and biplane react to Claude) and a nudge. Once a prompt has kept Claude busy for 45 s, the nudge shows one line under the chat suggesting a piece to open in another tab. It shows at most once per prompt and once per 15 min, and stays quiet while wait-fun is already running. `wait-fun nudge off|on` toggles it; `install --no-nudge` skips it. Details in [HOOKS.md](HOOKS.md).

A colour cheat sheet of every piece lives in [gallery.html](gallery.html), generated by `python3 tools/gallery.py`.

## Layout

```
wait-fun   single entry point (wf is an alias)
fun/       shared library
watch/     non-interactive animations
play/      interactive games
hooks/     Claude Code hooks: status (state file) and nudge (break hint)
```

Every script in `watch/` and `play/` carries a `META` dict (name, kind, blurb, credit) that the launcher reads with `ast`, without running the script. Credits are listed in [CREDITS.md](CREDITS.md).

## Animations

All accept `--fps N` (default 20; 12 for the calm ones: forest, reef, sandpile, skyline, campfire, hourglass, spacecol, catnap, sharks, koi, swirl, dyna, moire, codefire, meltdown, tixy, celestial, daisy, ink) and `--frames N` (render N frames, then exit).

Frames are diff-rendered (only changed cells are sent). In terminals that report focus, a piece drops to 1 fps while its window is unfocused; set `CLAUDE_FUN_NO_FOCUS_PAUSE=1` to turn that off. `tools/bench.py` measures CPU and bytes per frame for every piece; `tools/test_render.py` checks the diff renderer against a full redraw.

## Sound

Every piece plays sound by default. Pass `--mute` to silence one (`./wait-fun reef --mute`, or `./wait-fun --mute` for the whole rotation and the finale); in games, `m` also mutes or unmutes. Sound pauses while the terminal window is unfocused, like the frame rate.

- `CLAUDE_FUN_SOUND=0` turns all sound off.
- `CLAUDE_FUN_VOLUME` sets the volume from 0.0 to 1.0 (default 0.5).

Ambient themes of the watch pieces: campfire (crackle and rumble), reef (low ocean wash under a faint pad, with bubble pops at the surface, vent gurgles and a distant whale call when the whale passes), forest (wind and birds), jellyfish (pad and shimmering bells, with a soft glassy chime when a near jelly flashes), blackhole (sub drone and heartbeat), skyline (lo-fi electric piano over a distant traffic hush, with a far siren or train at night and birdsong when birds cross at dawn), sandpile and spacecol (sparse bells), catnap (slow purr while the cat sleeps; synthesized paw steps, meows, a trill and a yawn while awake). The newer ones: sharks (deep underwater drone with whale-like low swells, plus a swell of displaced water when a shark glides close), koi (soft pentatonic koto notes over water, with a soft water plop as a koi breaks the surface), swirl (slow evolving pad, with a soft swell as each form arrives), dyna (sparse brush swishes and a soft bell), moire (two slightly detuned tones beating slowly), codefire (crackle over a low hum), meltdown (warm lo-fi drone with tape wobble), tixy (gentle arpeggio), celestial (low drone under a slow pad with distant bells), daisy (soft pad under sparse glitch clicks, with a glitch blip on each cut), ink (a faint water hush under an airy pad, with a soft drip as a blot pools). Loops are gapless: the next one starts a moment before the current one ends.

Playback goes through a system player: `afplay` on macOS, otherwise `paplay`, `ffplay` or `aplay` (aplay ignores the volume). With none installed everything stays silent and one note is printed on exit.

All music, ambience and effects except bonkyon's are synthesized by `fun/synth.py` (stdlib only) and rendered once into `~/.cache/claude-fun/sounds/`; editing `synth.py` re-renders them on next use. `python3 fun/synth.py` renders every sound into a temp folder and prints timings.

bonkyon uses Srijan Paul's original sounds. The first run with sound downloads them in the background from [the Bonkyon repo](https://github.com/srijan-paul/Bonkyon) into `~/.cache/claude-fun/sounds/bonkyon/` (about 31 MB of music, converted to AAC with `afconvert` on macOS, about 3 MB); the game starts right away and the music begins when the download finishes. Offline, it says so once and uses synthesized stand-ins. Nothing is vendored here; credits are in [CREDITS.md](CREDITS.md).

## Shared modules

- `fun/term.py`: alternate screen, canvas, frame loop, status file.
- `fun/game.py`: raw keyboard input (arrows, WASD, space), high scores, "Claude's done" check.
- `fun/braille.py`: sub-cell drawing with braille dots (2x4 per cell).
- `fun/audio.py`: music and effects through a system player subprocess.
- `fun/synth.py`: the synthesized sounds and their cache.

Some react to Claude's state; see [HOOKS.md](HOOKS.md). More ideas: [IDEAS.md](IDEAS.md).

## Requirements

Python 3 and a 256-colour terminal. `NO_COLOR` is respected. The launcher follows symlinks to find its scripts, so you can link `wait-fun` anywhere.

## Contributing a piece

1. Put the script in `watch/` (non-interactive) or `play/` (interactive).
2. Add a module-level `META` dict near the top, before the imports. The launcher parses it with `ast.literal_eval`, so keep it literal:

   ```python
   META = {"name": "forest", "kind": "watch", "blurb": "one line",
           "credit": {"type": "inspired by", "who": "author or project", "url": "https://..."}}
   ```

   `type` is `"inspired by"` or `"taken from"`; use `None` only for fully original work. An optional `"variants": {"name-x": ["--flag"]}` adds extra launcher entries.
3. Insert the repo root into `sys.path` from `__file__`'s real path before `from fun import ...`, as the existing scripts do.
4. Support `--fps` and `--frames N` (via `term.make_parser` / `term.run`) so it can be smoke-tested.
5. Run `./wait-fun credits --markdown` and update [CREDITS.md](CREDITS.md).
